## next.html 当前已实现

### 数据驱动与中文展示
- 概览、人物、世界、时间线、旅程、能力、携带、项目、情报均从 JSON 渲染；
- 可选字段缺失时容错；
- 页面展示字段统一中文，内部 JSON 键名不会直接暴露给用户。

### 人物页包含“我”
- 徐长卿作为第一视角档案主体置顶显示；
- 不复制到 `people.json`，避免出现两个主角实体；
- 点击本人卡片仍读取 `player.json` 的唯一权威数据。

### 存档概况与叙事前沿分离
网站顶部现在区分：

- **完整存档规模**：人物、事件、章节、能力、项目、情报等数量；
- **最新叙事前沿**：只表示下一次从哪里继续。

避免把“最后一句剧情”误认为完整存档。

### 多世界作用域
- 当前世界；
- 全部世界；
- 世界01 / 未来世界02 / ……；
- 世界列表从 `data/worlds/index.json` 动态读取。

### 稳定实体与关联
已纳入稳定 ID：
- 玩家；
- 世界；
- 地点；
- 人物；
- 能力；
- 物品；
- 货币；

时间线、章节、项目、情报通过稳定 ID 建立前向引用，并自动生成 Backlinks / 反向关联。

### 事件与地点
- `timeline.json` 的事件使用 `locationIds` 单独关联地点；
- 事件详情可直接跳到发生地点；
- 地点详情通过反向关联看到在那里发生过的事件；
- 当前已补充镜州初始区域、七玄门、嘉元城方向客栈、青石山、太南谷外围溪边、太南小会集市、齐家庄等可关联地点。

### 实体详情抽屉
点击人物、能力、事件、章节、项目、情报、世界、地点、物品等实体，会在右侧打开详情抽屉。

当前支持：
- 人物：完整已知资料、信息来源、反向关联；
- 徐长卿：当前状态、现实背景、性格倾向与关联记录；
- 能力：来源、效果、限制、跨界状态、最早关联事件、相关正史章节；
- 项目：参与者、已确认、仍未知、缺少条件、风险；
- 情报：结论、证据链、仍未知、关联对象；
- 事件：时间、世界、摘要、发生地点、人物/能力/项目关联；
- 章节：卷、时间范围、摘要、关联对象、唯一 Markdown 正文来源；
- 世界 / 地点：世界规则、地点、价格、归属和事件反向关联；
- 物品 / 货币：数量、来源、位置与跨界状态。

## 自动诊断

### 浏览器端
`next.html` 会检查：
- 重复 ID；
- 无法解析的引用；
- 关键结构提醒；
- 实体与引用数量。

### GitHub Actions
- 动态加载世界注册表中的所有世界；
- 检查世界、地点、人物、能力、物品、事件、章节等引用；
- `event.locationIds` 必须是地点实体；
- 检查章节正文来源；
- 检查项目、情报数组结构；
- 检查隐藏功能注册与后台设定路径；
- 运行 `node --check assets/next.js` 和 `node --check assets/next-enhancements.js`。

## 项目命令

只保留两个：

- `存档`：续档、当前状态、结构化数据、网站数据与必要正史章节一起保存；
- `读档`：读取续档入口及权威档案后继续游戏。

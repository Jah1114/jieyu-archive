## 存档事务保护

已建立：

`archive/SAVE_TRANSACTION.json`

支持三种状态：

- `clean`：可安全读档 / 可开始新存档；
- `in_progress`：存档正在进行或可能中断，禁止正常续写；
- `repair_required`：已确认需要修复，禁止继续游戏。

事务协议要求：

- 读档第一步检查事务状态；
- 存档先读取 GitHub 最新文件与 SHA；
- 正式写入前置为 `in_progress`；
- `CONTINUITY.md` 接近最后更新；
- 自动校验和关键文件复核完成后才能恢复 `clean`；
- GitHub 未真实写入 / 校验未通过时，不允许声称“存档完成”。

## 长期地点规则

当前地点档案采用“长期记忆节点”规则，不记录所有一次性坐标。

长期保留标准：

- 重复 / 长期停留；
- 重要城市、宗门、据点或枢纽；
- 承载重大事件且有持续意义；
- 与长期联系人、资源、项目或资产有关；
- 未来有合理重访可能。

普通客栈、路边、临时溪边、普通摊位、一次性委托地点通常只留在正文 / 事件中。

## 资源与资产原则

长期档案当前只保存：

- 徐长卿私人资源；
- 有长期意义的物品；
- 稳定资产。

临时小队零钱 / 一次性平摊费用不进入长期“共同资金”字段。

未来只有出现稳定组织、仓库、据点、飞船或长期基金时，再建立共同资产体系。

`data/features.json` 已注册界网后台功能。

原则：

- 界网是历代行者自行建设的跨世界信息基础设施；
- 不是界域官方系统；
- 后台设定可以存在；
- **只有徐长卿在正史中实际接触并确认后，才能公开解锁第一视角界网视图。**

未解锁阶段：

- 不显示界网导航；
- 不显示好友 / 私信 / 社区 / 节点；
- 不把后台资料当成角色已知。

## 自动诊断

### 浏览器端

检查：

- 重复 ID；
- 无法解析引用；
- 基础结构问题；
- 实体与关系数量。

### GitHub Actions

当前检查：

- `SAVE_TRANSACTION.json` 事务状态；
- 多访问实例注册；
- 重复 ID；
- 世界 / 地点 / 人物 / 能力 / 物品 / 事件 / 章节 / 项目 / 情报引用；
- 章节正文来源；
- 隐藏功能与后台设定路径；
- 前端关键文件存在；
- `assets/next.js`、`assets/next-enhancements.js`、`assets/next-relations.js` JavaScript 语法。

当前继续增强方向：跨文件语义一致性，例如当前日、时段、地点和当前访问实例是否在多个权威文件中一致。

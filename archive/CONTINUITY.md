# 对话续档入口（Continuity Handoff）

> 用途：GitHub 侧跨对话续档入口。动态剧情以本文件及相关权威档案为准。稳定安全规则以项目来源中的《界域长期项目_统一运行规范_GitHub活协议版.md》为准；当前仓库架构与实际读写路径以 `archive/OPERATION_PROTOCOL.md` 为准。

## 最重要的操作规则

**每一次 `读档` 和每一次 `存档`，都必须在本次操作中重新：**

1. 查看项目来源中的统一运行规范；
2. 读取 `archive/OPERATION_PROTOCOL.md`；
3. 读取 `archive/PERSISTENCE_MAP.json`；
4. 再按最新协议读取 / 操作 GitHub。

不得因为当前聊天早些时候已经读过规则，就假定那一份仍是最新版。

## 两个核心命令

### `读档`

读档是只读操作。本次操作必须先重新查看项目来源，然后依次读取：

1. `archive/SAVE_TRANSACTION.json`
2. `archive/OPERATION_PROTOCOL.md`
3. `archive/PERSISTENCE_MAP.json`
4. 本文件 `archive/CONTINUITY.md`
5. `archive/CURRENT_STATE.md`
6. `data/meta.json`

只有同时满足 `state = clean`、`activeTransaction = null`、`repair.required = false`，并且核心连续性文件可以互相解释，才允许继续读取人物、能力、携带、世界、时间线、章节、项目、情报等权威文件并恢复游戏。

### `存档`

每次存档都重新同步来源规则、活协议、持久化映射、事务状态、核心连续性与所有目标文件最新 SHA；根据本轮真实变化声明 `changeDomains` / `targetFiles`，先将事务设为 `in_progress`，按最小变更写入并复核，等待自动校验通过后才恢复 `clean`。任何部分写入、协议冲突、版本冲突或校验失败都不能宣布存档完成。

**“最新叙事前沿”只是续写坐标，不等于完整存档。**

## 叙事与玩法规则

- 除执行 `读档` 后开头允许有必要的游戏外状态说明外，一旦进入正式剧情，普通回复应持续沉在故事中。
- 不用“你准备怎么做？”“请选择行动”“接下来可以……”等主持人式界面收尾；用户的自然语言输入本身就是徐长卿的行动、语言、思考或意图，世界直接作出反应。
- 不给固定 A/B/C 菜单。
- 世界独立运行，NPC 有自己的动机与生活。
- 原作是初始条件，不是剧情铁轨；世界02不得因为模型知道《赛博朋克 2077》剧情就自动把徐长卿塞进固定任务线。
- 信息严格不全知；具体城市、年代、帮派 / 公司关系、现场枪战原因等在徐长卿调查前都保持未知。
- 战斗、交易、资源、时间、伤势有现实成本；死亡原则真死。
- 徐长卿不强行当领袖，也不为了制造剧情主动做不合理高风险选择。
- 平静生活、训练、研究、挣钱、社交与低风险路线都是有效玩法。
- 具体小说文体以项目来源中的《界域_叙事文体与小说写作规范_v2.md》为准；已经验证过的重复流程可压缩，只详细呈现新信息、新变化和重要人物互动。

# jieyu-archive

界域档案：长期无限流文字RPG的第一视角档案与正史存档库。

## 使用约定

- **聊天中的“查看信息”**：显示当前即时HUD。
- **“同步档案”**：把已发生且可可靠确认的游戏进展同步到本仓库。
- 网站展示只使用徐长卿当前认知，不展示NPC后台秘密或未获知事实。
- 无法可靠还原的历史细节不会硬补。
- 早期已废弃的非正史开局不进入正式档案。

## 仓库结构

- `index.html`：GitHub Pages 第一视角档案网站。
- `archive/CURRENT_STATE.md`：当前角色、能力、资源与未解问题快照。
- `archive/PEOPLE.md`：人物档案（徐长卿视角）。
- `story/world01_fanren/CHAPTERS.md`：世界01《凡人修仙传》正史章节级归档。当前为依据可靠记忆重建的整理稿，不伪装成逐字聊天记录。
- `lore/SETTING.md`：后台项目设定，包括界域、行者社会、无量灵海、界网与叙事原则。此目录不代表徐长卿当前知道这些内容。

## 当前同步基准

《凡人修仙传》· 太南小会时期 · 入界第123天左右。

后续会继续按“当前档案 / 正史章节 / 项目设定 / 网站展示”四层维护。
